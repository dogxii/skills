# 界面

像系统自带的工具：安静、紧凑，打开就看懂。

尺寸、字号和颜色直接用模板 `Theme.swift` 的默认值。和产品冲突时才改一项，并写明原因。

- 面板只回答一个问题，最重要的状态放在最上面。图标能传达的状态，不要让人点开才看到。
- 平时只显示必要内容，次要信息和操作放到悬停或右键。
- 悬停不改变面板尺寸，也不让其他内容跳动。
- 列表里的同类内容对齐成列，数字右对齐。
- 空状态给出下一步操作，不留空白。
- 颜色用来提示状态，不做装饰。层次靠 `labelColor` 的透明度，深浅色和半透明背景才都成立。
- 会变化的数字用等宽数字，避免跳动。
- 改变状态的操作要点到明确的按钮上。只有不易恢复的操作才弹确认。
- 文案短。报错时说明发生了什么、下一步怎么做。
- 动效只说明状态变化，约 0.2 秒。遵守「减弱动态效果」；面板关闭后停止，闲置时不产生唤醒。
- 可交互的元素都有悬停反馈和辅助功能标签。
- 只留一个记忆点，其余都退后。
